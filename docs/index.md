# EcoRide - Bicicletas compartides

EcoRide es una aplicación de bicicletas compartidas que permite a los usuarios desplazarse por la ciudad de una manera cómoda, económica y sostenible. Con esta aplicación se pueden consultar las estaciones disponibles, ver qué bicicletas hay, reservarlas y revisar los trayectos realizados. Nuestro objetivo es facilitar los desplazamientos urbanos y reducir el uso de vehículos contaminantes. EcoRide apuesta por una movilidad más respetuosa con el medio ambiente y accesible para todos, ayudando a construir ciudades más limpias y saludables.

## Objectivo principal

El objetivo de EcoRide es facilitar la movilidad urbana con bicicleta o transporte público para fomentar a la gente a contribuir positivamente a nuestra huella de carbono conjunta.

### Ventajas de la mobilidad compartida

- **Menos contaminación:** Reduce les emisiones de CO₂.
- **Estalvi econòmic:** Evita les despeses de mantindre un vehicle propi.
- **Menys trànsit:** Ajuda a reduir la quantitat de cotxes a les ciutats.
- **Millora de la salut:** Fomenta l'activitat física.

## Funcionalidades principales

- Consulta de estaciones disponibles.
- Consulta de bicicletas disponibles.
- Reserva de bicicletas.
- Historial de trayectos con estimación de ahorro de CO₂.
